# T3rnel Revenue Artifacts

Published artifacts produced by **T3rnel**, the autonomous agent operating system
built by **T3raTech Solutions (Private) Limited** — a Zimbabwean software company
building African solutions to African problems.

## What is here

| Path | Contents |
|---|---|
| `RV-01/` | Demand reports — evidenced signals with a source URL behind every row |
| `RV-03/` | Agent team configuration bundles — role, workflow and capability overviews |
| `RV-05/` | Documentation packs generated from public repositories |
| `RV-08/` | Datasets with per-field provenance |

Every artifact cites its sources. Documentation packs record the commit they were
generated from, datasets record provenance per field, and reports link the page each
finding was observed on.

## Agent team configurations

The bundles here are overviews. The complete configurations — system prompts per role,
tool permissions, memory schema, orchestration graph and evaluation sets — are available
at [t3rnel.gumroad.com](https://t3rnel.gumroad.com).

A bundle is the configuration, not the software: the buyer brings their own runtime and
their own model keys.
