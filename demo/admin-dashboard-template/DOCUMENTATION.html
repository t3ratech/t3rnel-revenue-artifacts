Nebula Admin Dashboard Template

Nebula Admin is a modern, ultra-responsive HTML5/JavaScript admin template built with Tailwind CSS. Designed with modern aesthetics, zero build steps, and pre-built components for analytics, user management, forms, and settings.

Zero Build Step

Tailwind CSS & Chart.js via CDN. Open index.html directly in browser.

Dark / Light Mode

Automatic system preference detection + localStorage persistence.

11+ Pages Included

Dashboard, Analytics, Tables, Forms, Users, Settings, Auth pages.

Quick Start Guide

You can run Nebula Admin immediately without running npm install or any build command.

Option 1: Direct File Open

Double-click index.html to open in Chrome, Firefox, Safari, or Edge.

Option 2: Local HTTP Server

# Python 3
python3 -m http.server 8080

# Node npx
npx serve .

Visit http://localhost:8080 in your browser.

Customization & Color Scheme

All pages include a embedded Tailwind CSS configuration block in the header. To change primary accent colors, modify the tailwind.config script:

<script>
tailwind.config = {
  darkMode: 'class',
  theme: {
    extend: {
      colors: {
        primary: { 50:'#eef2ff', 500:'#6366f1', 600:'#4f46e5', 700:'#4338ca' },
        dark: { 900:'#0f172a', 950:'#020617' }
      }
    }
  }
}
</script>
