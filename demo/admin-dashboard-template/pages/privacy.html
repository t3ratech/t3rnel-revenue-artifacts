Nebula Admin

Privacy Policy

Effective Date: 16 August 2026

1. Data Collection

Nebula Admin is a static HTML template. It does not collect, store, or transmit personal data to any server. All preferences (such as theme settings) are stored locally in your browser via localStorage.

2. Third-Party Services

This template loads external resources from CDN providers (Tailwind CSS, Chart.js, Lucide Icons, Google Fonts). These providers may collect standard web analytics data.

3. Cookies

This template does not set cookies. Theme preference is stored in browser localStorage only.

4. Your Rights

Since no personal data is collected or stored by this template, there is no data to access, correct, or delete.

5. Contact

For privacy-related questions, contact the template author through the marketplace where you purchased this template.
